# Disclaimer

This repository documents one reviewed, approval-gated workflow. It is not a universal cleanup script, a guarantee of recoverable space, or a substitute for backups and device-owner judgment.

Filesystem layouts, APFS behavior, application data, cloud synchronization, links, permissions, and recovery options vary. A category that was safe in one reviewed run may be unsafe on another machine or at another time. Revalidate every target, retain private evidence, and stop when scope or ownership is uncertain.

The project intentionally provides no machine-specific deletion playbook. Examples and templates describe evidence and controls, not authorization to remove data.
